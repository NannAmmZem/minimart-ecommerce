  🔑 NEED A GITHUB TOKEN?
═══════════════════════════════════════════════════════════════

GitHub requires a Personal Access Token (not password):

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name it: "Mini Mart Development"
4. ✓ Check ONLY: repo (Full control of private repositories)
5. Click "Generate token" at the bottom
6. ⚠️ COPY THE TOKEN - You won't see it again!
7. Use this token as PASSWORD when pushing

Token looks like: ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
