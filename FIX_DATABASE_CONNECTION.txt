  📝 MANUAL FIX FOR LARAGON
═══════════════════════════════════════════════════════════════

If Laragon won't start MySQL:

1. Check if another MySQL is running:
   - Open Task Manager (Ctrl+Shift+Esc)
   - Look for "mysqld.exe" processes
   - End any running MySQL processes

2. Check if port 3306 is used:
   - Open PowerShell as Administrator
   - Run: netstat -ano | findstr :3306
   - If port is used, stop that process

3. Try starting MySQL only:
   - Right-click Laragon icon
   - Menu > MySQL > Start

4. Check MySQL service:
   - Open Services (services.msc)
   - Look for "MySQL" services
   - Stop any running MySQL services
   - Then start Laragon again
