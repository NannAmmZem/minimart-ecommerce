🔧 TROUBLESHOOTING:
================================================================

IF VIRTUAL HOST ISN'T WORKING:
1. Check hosts file: C:\Windows\System32\drivers\etc\hosts
   Should contain: 127.0.0.1 minimart.test
2. Restart Laragon

IF PORT 80 IS BUSY:
- Change Apache port in Laragon → Apache → Change Port
- Use 8080 or another available port
- Access site at http://minimart.test:8080

IF CSS ISN'T LOADING:
Run: npm run build

IF IMAGES WON'T UPLOAD:
Run: php artisan storage:link
