STEP 1: Create Supabase Account
--------------------------------
1. Go to: https://supabase.com
2. Click "Start your project"
3. Sign in with GitHub
4. Click "New project"
5. Fill in:
   - Name: minimart-ecommerce
   - Password: (create strong password - SAVE IT!)
   - Region: Choose closest to you
6. Click "Create new project"
7. Wait 2 minutes ⏳

STEP 2: Get Your Credentials
-----------------------------
1. In Supabase dashboard, click "Project Settings" (⚙️)
2. Click "Database" tab
3. Scroll to "Connection string"
4. Copy the URI (looks like):
   postgresql://postgres:[PASSWORD]@db.xxx.supabase.co:5432/postgres
   
5. Note down:
   - Host: db.xxx.supabase.co
   - Password: (the one you created)

STEP 3: Run Setup Script
-------------------------
1. Double-click: SETUP_SUPABASE.bat
2. Follow the prompts
3. Enter your Supabase credentials
4. Let it install dependencies and migrate
5. Done! ✨

═══════════════════════════════════════════════════════════════
  📝 MANUAL METHOD (IF SCRIPT DOESN'T WORK)
═══════════════════════════════════════════════════════════════

1. Install PostgreSQL driver:
   composer require doctrine/dbal

2. Update .env file:
   DB_CONNECTION=pgsql
   DB_HOST=db.xxx.supabase.co
   DB_PORT=5432
   DB_DATABASE=postgres
   DB_USERNAME=postgres
   DB_PASSWORD=your-supabase-password
   DB_SSLMODE=prefer

3. Clear cache and migrate:
   php artisan config:clear
   php artisan migrate:fresh --seed

═══════════════════════════════════════════════════════════════
  🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Error: "could not connect to server"
------------------------------------
Fix:
  - Check host and password in .env
  - Verify Supabase project is running
  - Check your internet connection

Error: "SQLSTATE[42P01]: Undefined table"
-----------------------------------------
Fix:
  - Run: php artisan migrate:fresh --seed

Error: "Class 'Doctrine\\DBAL\\Driver' not found"
-------------------------------------------------
Fix:
  - Run: composer require doctrine/dbal

Migration Fails:
----------------
Fix:
  - Check .env credentials
  - Run: php artisan config:clear
  - Try again: php artisan migrate:fresh

Can't Login After Migration:
-----------------------------
Fix:
  - Run: php artisan db:seed
  - This recreates admin and customer accounts
