About This Project

Mini Mart is a full-featured e-commerce platform developed from scratch using Laravel 12.x. This project demonstrates professional-level full-stack development skills, including backend API development, database design, authentication systems, and responsive frontend design.

The platform includes both a customer-facing shopping experience and a comprehensive admin dashboard for managing products, categories, and orders.
