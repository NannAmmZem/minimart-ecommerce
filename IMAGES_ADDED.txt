HOW TO UPLOAD REAL PRODUCT PHOTOS:
═══════════════════════════════════════════════════════════════════════

1. Login to Admin Dashboard
   http://127.0.0.1:8000/admin

2. Go to Products → Click "Edit" on any product

3. Scroll to "Product Image" section
   - You'll see current emoji image
   - Click "Choose File"
   - Select your photo (JPG/PNG, max 2MB)
   - Click "Update Product"

4. Done! Real photo replaces emoji placeholder


IMAGE SPECIFICATIONS:
═══════════════════════════════════════════════════════════════════════

Recommended:
  Size:      800x800px (square)

  Quality:   80-90%

TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════

Images not showing?
  → Run: php artisan storage:link
  → Clear cache: php artisan cache:clear
  → Refresh browser (Ctrl+F5)

Upload fails?
  → Check file size (< 2MB)
  → Check format (JPG, PNG, GIF, WEBP)
  → Check folder permissions

Emoji not showing?
  → Browser doesn't support SVG emojis
  → Upload real photo instead
